Detailed Description

Represents a Corintho game state.

Note
The class is designed to be as memory efficient as possible since it is contained in each node of the Monte Carlo Search Tree which is the main memory bottleneck of the program
The game state does not know if it is a terminal state This is deduced by the Node class from the return value of getLegalMoves (when there are no legal moves)

MoveMask Game::lineBreakers ( const SpaceInfo &  info,
const PresentLine *  lines,

privatenoexcept

The set of moves that break every line currently on the board.

One mask per line, ANDed together, rather than testing every move against every line. Four of the five ways to break a line are constant per shape and type and come straight from kLineBreakTable. The fifth – moving a stack onto the extending space – is the only one that depends on the board, and is masked by which moves currently start from a space topped by the line's type.
