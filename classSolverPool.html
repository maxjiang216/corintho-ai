Detailed Description

Threads that solve self-play positions off the engine's critical path (worklog 2026-09-25-nn-architectures, entry 14)

A game whose position reaches the solve horizon submits it and ends at once; its result is collected when the samples are written, so self-play iterations never wait for a solve. Each thread keeps one Solver whose table is never cleared: stored results and bounds are facts about positions, true in every game, so the table becomes a growing endgame cache.
