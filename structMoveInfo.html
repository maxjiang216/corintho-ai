Detailed Description

A move decoded into flat board indices.

The hot paths – legality and line breaking – want cell indices, not a Move object. Decoding an ID arithmetically costs several integer divisions by 3 behind a data-dependent branch chain, and it was measured at 10.7% of all instructions once it stopped being inlined.
