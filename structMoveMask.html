Detailed Description

A set of moves, one bit per move ID.

std::bitset gives no portable access to its underlying words, so the set bits cannot be iterated with a bit-scan instruction and constexpr tables of move sets cannot be built. Two explicit words fix both.

Note
Move IDs 0-47 are move-moves and 48-95 are places, so every move-move lives in lo. The dynamic part of line breaking concerns only move-moves, and therefore touches one word.
